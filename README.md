# PBO-Atlas

Mapas, spawns y pokédex de **Pokemon Blaze Online**. Explora las 4 regiones (Sinnoh, Jvaloh, Hoenn y Kanto), mira qué pokemon salen en cada ruta y descubre dónde capturar cualquier pokemon.

Herramienta de fans, no afiliada a PBO ni a Nintendo. Datos de spawns extraídos del [foro oficial de PBO](https://forums.pokemonblazeonline.com/) y datos de pokédex de [PokeAPI](https://pokeapi.co/).

## Desarrollo

```bash
npm install
npm run dev        # http://localhost:3000
```

## Actualizar datos

```bash
npm run data       # scrapea el foro + PokeAPI y regenera src/data/*.json
```
